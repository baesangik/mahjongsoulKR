mahjongsoulKR

일본 서버 작혼(game.mahjongsoul.com, 웹)의 화면 텍스트를 한국어로 바꿔주는 비공식 유저스크립트입니다. 번역을 따로 넣는 게 아니라, 게임에 이미 들어 있는 공식 한국어를 켜는 방식입니다.

설치 방법

1단계에서 브라우저 확장 Tampermonkey를 깔고, 2단계에서 위의 스크립트 설치 버튼을 누르면 됩니다.

1. Tampermonkey 설치

  1. 크롬 웹스토어의 Tampermonkey를 설치합니다. 엣지는 엣지 애드온에서 받아도 됩니다.
  2. 유저스크립트 허용을 켜야 합니다. 이걸 안 하면 스크립트가 아예 실행되지 않습니다.
    • 주소창에 chrome://extensions(엣지는 edge://extensions)를 열고 오른쪽 위 개발자 모드를 켭니다.
    • 최신 크롬에서는 Tampermonkey의 세부정보에 들어가 사용자 스크립트 허용도 켜야 합니다.
  1. 파이어폭스 부가 기능의 Tampermonkey를 설치합니다. Violentmonkey도 됩니다.
  2. 추가 설정은 필요 없습니다.
  1. 안드로이드용 파이어폭스를 설치합니다.
  2. 파이어폭스 메뉴 → 부가 기능에서 Tampermonkey를 추가합니다.
  3. 그다음은 PC와 같습니다.

사파리 확장 Userscripts나 Stay 앱으로 설치할 수 있습니다. 아직 테스트하지 않았습니다.

2. 스크립트 설치

  1. 이 페이지 위쪽의 스크립트 설치 버튼을 누릅니다.
  2. Tampermonkey 설치 화면이 뜨면 설치를 누릅니다. 이미 깔려 있으면 업데이트나 재설치로 나옵니다.
  3. 설치 화면 대신 코드가 그대로 보이면 Tampermonkey가 없거나 꺼져 있는 것입니다. 1단계를 다시 확인하세요.

3. 확인

  1. game.mahjongsoul.com에 접속합니다. 이미 열려 있었다면 새로고침합니다.
  2. 타이틀 로고가 작혼으로 나오고 버튼과 메뉴가 한국어면 성공입니다.

안 될 때

  • 일본어 그대로: Tampermonkey 아이콘을 눌러 mahjongsoulKR이 켜져 있는지 확인하고 새로고침하세요. 크롬이라면 1단계의 유저스크립트 허용을 다시 확인하세요.
  • 광고 차단기: 일부 광고 차단기가 유저스크립트를 막습니다. 게임 사이트에서만 꺼보세요.
  • 게임이 안 켜지거나 멈춤: Tampermonkey에서 스크립트를 끄고 새로고침해 보세요. 원래대로 켜지면 패치 문제이니 이슈로 알려주세요. F12 콘솔의 [mjs-kr] 로그를 같이 보내주면 빨리 고칠 수 있습니다.
  • 패치가 실패하면 스크립트가 스스로 꺼지고 게임은 일본어로 정상 실행되도록 만들어져 있습니다.

제거

Tampermonkey 대시보드에서 mahjongsoulKR을 삭제하고 새로고침하면 바로 일본어로 돌아옵니다. 게임 데이터나 설정에는 남는 게 없습니다.

원리

일섭 클라이언트에도 한국어 텍스트와 폰트가 들어 있지만, 일섭에서는 표시 언어를 일본어로만 고정합니다. 이 스크립트는 게임이 받는 Lua 스크립트 번들 하나에 몇 줄을 덧붙여서, 서버 설정(client_language)은 그대로 두고 표시 언어(prefer_language)만 한국어로 바꿉니다. 번들 이름이나 암호 키가 바뀌어도 자동으로 찾아내기 때문에, 게임 업데이트 때마다 패치를 고칠 필요가 거의 없습니다. 자세한 내용과 소스는 GitHub에 있습니다.

주의

공식이 아닌 팬메이드 모드이며, 게임 운영사와 관련이 없습니다. 클라이언트를 수정하는 방식이라 계정 제재 가능성이 0은 아닙니다. 사용에 따른 책임은 사용자 본인에게 있습니다.
